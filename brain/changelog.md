# Brain Changelog

Shared-brain change log for **team** workspaces. When someone edits a shared
file (`brain/context.md`, `brain/contexts/*`, an agent, a hook, a skill), `/close`
appends a dated line here. On `/start`, teammates read the most recent entries so
they know what changed under them since they last worked.

Solo workspaces can ignore this file — it stays empty.

Newest entries on top. One section per day, one bullet per changed file.

Format:

```markdown
## YYYY-MM-DD — <handle>
- `path/to/file` — what changed, and why it matters to the rest of the team
```
